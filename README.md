# Mint

**Mint** là ứng dụng báo giá gia công kỹ thuật số — thả file 3D (STL, OBJ, 3MF) vào, nhận báo giá ngay lập tức. Phát triển bởi **MakeNode**.

**Mint** is a digital manufacturing quoting app — drop a 3D file (STL, OBJ, 3MF), get an instant price. Developed by **MakeNode**.

**Mint** 是一款數位製造即時報價應用程式 — 拖放 3D 檔案（STL、OBJ、3MF），立即取得報價。由 **MakeNode** 開發。
